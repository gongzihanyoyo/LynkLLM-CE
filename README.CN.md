# LynkLLM-CE

轻量级BYOK式AI聊天网页客户端

by [**Jitaimei Studio™**](https://www.jitaimei.top) with **DeepSeek-V4.1-Flash**

## 功能特性

- 无需下载，打开即用。
- 数据存储在本地，充分保障隐私。
- 直接连接接口，无需中转，高速输出。
- 自由管理多个模型，支持图片输入与输出。
- 支持接入[Tavily](https://www.tavily.com)，让AI自动搜索信息。
- 提供上下文长度警告，防止因长度过长导致意外中断。
- 提供MCP连接支持，扩展更多能力。
- 提供[油猴增强脚本](https://www.tampermonkey.net/script_installation.php#url=https://lynkllm-ce.pages.dev/LynkLLM-CE-Enhancer.user.js)以绕过CORS限制。

## 注意事项

- 对于某些带有 CORS 限制的 API，请[安装增强脚本](https://www.tampermonkey.net/script_installation.php#url=https://lynkllm-ce.pages.dev/LynkLLM-CE-Enhancer.user.js)。
- 目前仅支持 OpenAI 格式；其他格式暂不可用。
